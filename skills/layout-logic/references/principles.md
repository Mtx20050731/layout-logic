# 通用规范：内容、结构、表达

这些是课件与所选作品的综合方法，适用范围以当前任务为准。作品的来源与观察见 designer-studies.md；课件映射见 provenance.md。

## 规则的三种强度

| 强度 | 内容 | 处理方式 |
|---|---|---|
| 功能底线 | 必需事实准确完整、主体可识别、目标条件下可读、交付正确 | 先修复，再谈效果；艺术性含义可以有悬念 |
| 项目约定 | 版心、网格、字级、间距、色彩角色、图注位置、裁图逻辑 | 系列内稳定；有理由的例外保留锚点并记录 |
| 表达选择 | 对称/不对称、斜排、裁切、透叠、密集拼贴、景深 | 按内容选取并检验，不提升为通用禁令 |

## 十二条可迁移原则

**P01 内容先分角色。**区分吸引注意的主题、解释与证据、检索/行动信息。标题不是必然最大：体育海报可以先见运动员，优惠海报可以先见优惠；但两者应导向准确的信息。

**P02 层级依赖关系。**先用一个主要变量建立层级，再加必要辅助变量。标题、日期同时大、粗、亮且倾斜，会产生竞争。多焦点可用于并列议题，但应形成组而非随机争夺。

**P03 网格从内容生成。**先选边距与栏的职责，再选数量。连续阅读需要稳定栏宽与行距；主视觉海报可用少量锚线；几何图形可用模块。不要默认 12 栏、黄金比或“只能居左”。

**P04 对齐既有几何也有视觉。**圆形、尖角、标点、细字和粗字的外框并不等于视觉边界。先对齐共同基线/边缘，再做小幅光学校正；说明校正目的，不制造无法解释的随机偏移。

**P05 相对对称是重量平衡。**图片面积、黑白对比、面孔、文字密度、饱和色与方向都影响重量。不对称可稳定，对称也可有张力；不预设固定情绪。

**P06 让隐性点线面先工作。**字组、图片边缘、视线、重复位置和空白边界都可分组与引导。可见分割线、色块和圆点只在它们提供额外信息或情绪时加入。

**P07 留白承担动作。**外边距保护画面，组间空白分段，主体周围空白提高权重，密集区后的空白提供停顿。白色不是唯一留白；噪点/纹理较少的暗区也能呼吸。留白量由内容决定。

**P08 字体有职责。**字型数是管理变量，不是美感定律。同一字族用字重与尺寸可形成大部分层级；有明确角色时可以使用多字型。正文可读性、标点、混排与语言特点比“最多三种字体”更关键。

**P09 图文共享关系。**让文字呼应主体的边缘、视线、运动线或几何模块。图文穿插/材质对比只在维持必要字形、人物脸部及商品特征时使用。识别失败时减小遮挡或另设完整信息层。

**P10 颜色和材质承担角色。**定义背景、主体、强调和解释的职责，不规定通用色数。强色彩用于强调还是气氛须明确；黑白摄影不自动“高级”。专用风格中的印刷色数/材质要求仍须遵守。

**P11 变化来自可识别的秩序。**重复的结构中改变一处尺度、方向、颜色或内容，能产生记忆点；没有重复和共同锚点的变化容易变成任意排列。密集海报可让边框、分区和主要标题维持方向。

**P12 表达适配阅读条件。**远看要识别主体与主信息，近看要取到必要事实。近大远小、虚实、遮挡、色温与透视只作为可选纵深暗示。手机、印刷、投影、多语版本均需重新校验。

## 网格参数的计算与记录

明确单位。若画布宽度 W、左右边距 L/R、等宽栏数 n、栏间距 g，则栏宽 c = (W − L − R − (n−1)g) / n。跨 k 栏宽度 = k·c + (k−1)g。相邻文本区之间的间距应按内容关系选，不以“填满网格”为目的。基线单位可与正文行距协同，混合字号或注释允许局部节奏；不要为强制压入基线而扭曲字符。

**计算示例，仅是项目起点：**1080×1440 px 手机活动海报，左右各 72 px，4 栏，栏间 24 px，则每栏 216 px；跨两栏 456 px。主标题跨四栏，商品图跨两栏，说明跨两栏。但标题与说明的具体字号仍需在目标显示宽度检查；该数值不代表教材、设计师或网格书的规定。

项目记录至少包含：成品尺寸与用途、主体与信息顺序、版心与栏/锚线、字级与字重/行距、组内/组间距、色彩职责、图片裁切与保护区域、允许的例外。系列变体可移动主视觉，但保留标题/品牌/日期等所需稳定角色。

## 中文及多语排版

中文通常先保留自然阅读与标点完整；竖排使用真正的竖排能力或明确校验后的人工编排，不能简单把整段横排旋转。检查开头的闭括号/句号、末尾的开括号、被拆散的数字日期及专名。英文断行遵从短语意义；拉宽字距不能代替合理行长。中英/日英混排按实际字形的视觉高度、基线和字重调整，不盲用相同数字字号。双语并不必等大，但对应、地位与所需完整性要清楚。

## 从原课件保留与修订的内容

保留十种文字对比、五种构图关系、有形/无形点线面、穿插叠压透叠、轻重留白及纵深方法作为方法库。修订“方法越多越好”“固定构图必然对应某情绪”“远冷近暖是定律”。把标题裁切、字形实验或多字型视为有条件的选择，而非一律禁止。
