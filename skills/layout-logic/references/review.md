# 评审与交付

## 按失败影响排序

| 检查 | 看什么 | 具体修法示例 |
|---|---|---|
| 内容与主体 | 文案是否准确；产品、人物、主题是否可识别；必留项是否出现 | 恢复误删的限制条件；移开压住品牌字的标题；调整人物裁切 |
| 阅读路径 | 第一眼能定位主体/主信息；必要事实能在细读时检索 | 缩小抢眼辅图；将主标题与正文拉开字重；把日期地点成组 |
| 结构与重量 | 对齐和间距是否可解释；重心是否支持意图 | 共用文本左缘；统一同级标题；移动高对比区平衡偏重 |
| 色彩与材质 | 文字背景能否分开；纹理是否损害识别；是否符合指定风格 | 改局部明度/底色；减少正文区颗粒；按指定印刷色数重设 |
| 字体与排版 | 小字、混排、断行、标点、裁字、叠字和字距 | 修标点禁则；保持日期数字完整；调整视觉基线；减小遮挡 |
| 留白与图像关系 | 空白是否分组、停顿、保护主体；参考图职责是否清楚 | 拉开异类组间距；让主体朝向空白；明确图片是内容还是氛围 |
| 纵深与表现 | 遮挡、虚实、透视是否建立合理关系 | 删掉无意义模糊；只在可容忍区穿插；缩减争抢注意的技巧 |
| 格式与输出 | 尺寸、边界、清晰度、字体、交付类型是否符合 brief | 手机版重新排文案；按实际投影距离复核；导出后检查页边 |

优先修会让信息错误、读不到或误认主体的问题，再修秩序和情绪。不要用“高级”“太乱”等形容词替代可定位的说明。

**评审示例：**“右下日期和背景纹理明度接近，手机预览时难以检索。把日期移入稳定的纯色信息区，并提高字号或字重；标题的斜向节奏可以保留。”如果没实际查看手机预览，把表述改为“有检索风险，需在目标显示宽度复核”。

## 不同媒介如何调整

| 媒介 | 优先解决 | 不宜直接迁移 |
|---|---|---|
| 印刷/展览海报 | 远看主体与主信息、近看细节；成品安全边界和印刷条件 | 把网页小字参数直接当印刷字号；未经校验声称印前通过 |
| 手机/社交图 | 缩小显示后的层级、小字、平台遮挡区域 | 整页等比例缩小；用过密图像换主题冲击 |
| 幻灯片 | 会议观看距离、单页阅读量、连页一致性 | 套用近距离海报中的脚注密度；缩正文保留装饰 |
| 书刊/报告 | 连续阅读、栏目、跨页节奏、图注和出处 | 每页都当独立海报；为了表现使用难读的正文方向 |
| 多语版本 | 相同语义对应、不同文字长度与字形特征 | 机械复制断行、尺寸；把横排旋转当正确竖排 |

数字需按媒介确定。若任务明确为网页且适用无障碍标准，按该项目标准核对；不要把屏幕对比数值直接宣传为印刷海报的通用印前标准。

## 交付核对

按任务输出成品或具体方案，附主要选择及必要参数。简短说明：成立之处、规则冲突、做了什么调整，以及实际验证/未验证的边界。版式方案可附“画布—主体—阅读路径—结构—字级—留白—巧思—验证”记录；简单修改不需要强制八段报告。

只有真正执行过，才说已渲染、已做读者测试、已检查字体嵌入、已印前验证。若只能审阅图片或给结构建议，应准确说明依据。缺少某个文件不会阻止其余工作，但不得补造文件内容或页码。
