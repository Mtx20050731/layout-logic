# 十二个有条件的小巧思

以下操作是作品研究与课件的再提炼，不是作者原话或照搬模板。编号 S 对应 designer-studies.md 的案例；P 对应 principles.md。选择能说明主题的机制，再检查可读性。简单设计无需为了“创意”增加技巧。

| 方法 | 用来解决什么 | 实施与验证 | 何时退回 |
|---|---|---|---|
| T01 图形和字共享模块 | 减少图文各做各的感觉 | 从主体形态取一个宽度、角度或单元，用到字组/标注的边界；不用复制原作图形。看二者是否形成清楚的关系。S01/S07 | 模块令字被拉扁、主体变形或必要信息无处安放 |
| T02 重复里改变一次 | 在稳定系列中制造记忆点 | 建立可见的重复，再改变一项颜色、方向、尺度或内容。问变化是否能对应核心议题。P11 | 变化与主题无关，或多个例外互相争抢 |
| T03 借一条走势排文字 | 增强引导与运动 | 用人物视线、身体姿态、物体边缘或主斜线联系标题；日期等检索信息可保留稳定横排区。S05/S06/S08 | 阅读需要频繁转头，或主路径带离信息 |
| T04 字也构成主视觉 | 让纯文字材料有表现力 | 通过尺度、字重、字距、方向或断行改变语气；先保证完整标题可辨，再精调字形。S07/S08 | 用字符变形代替概念，标题辨识成本高于主题需要 |
| T05 图文轻度穿插 | 形成共同主体与前后 | 只遮能容忍的字形部位，让必要笔画、面孔、产品识别点留下；检查缩略图和真实尺寸。课件第四节 p8–12 | 遮挡导致错字、误认人物或无法识别品牌 |
| T06 负空间出现第二层意思 | 增强回看和主题联想 | 先让主形成立，再让间隙承载一个与主题有关的形；保持两种读法不损害事实信息。P07，机制性综合 | 需要长解释才能看见，或关键内容藏进谜题 |
| T07 一个视觉矛盾 | 将主题转成可记忆的概念 | 改变一个熟悉关系，如方向、用途或尺度；周围信息保持容易读取。S03/S11 | 矛盾只剩奇观，与主题无关；不要强制所有项目都用 |
| T08 把空白放在“视线要去的地方” | 给主体呼吸并连到信息 | 依据朝向/动作留出空间，在适当位置安放短标题；先试不加引导箭头。课件第三节 p10 | 主体被迫缩小，空白挤掉必留信息 |
| T09 用局部细节作回报 | 让近读增加理解 | 远看只保留可辨主体与核心层，近看可读小注、日期或主题细节。S04/P12 | 把必需条款做成只有设计者放大才看得到的装饰 |
| T10 图像与文字共用“材料语气” | 建立情绪一致性 | 粗颗粒摄影可配有相应力度的标题，但正文仍用清楚字形；不必让全页都加纹理。S09/S10 | 材质影响识别、混合输出产生噪点或印刷失真 |
| T11 大区块稳定、小区块有张力 | 允许密集内容仍可检索 | 用一条主轴、边框或稳定信息区支撑内部变化；张力来自相对关系。S02/S04/S09 | 区块边界、重心和角色一起变化，失去可辨结构 |
| T12 同系列保留锚点、变一个主要关系 | 适配海报/手机/投影 | 固定品牌角色、信息等级或少数对齐线，按新比例改图文关系；重新检查裁切和字级。S08/P12 | 直接等比缩小导致小字难读，或每张都换一整套语言 |

## 避免模板感的选择方式

写出内容中的一个动词或关系：连接、分离、汇聚、碰撞、漂移、折返、等待、增长等。把它转成排版动作，再检验是否适合该主体。比如“汇聚”可让小模块朝共同焦点组织，“等待”可借留白和停顿，“分离”可让字和图保持有意义的距离。动作由内容产生，不能从参考画面表面照搬。

两个快速回退试验：①拿掉技巧后，内容是否更容易理解？若明显改善，减弱或换法。②保持字级与结构，替换颜色和素材后还能识别核心关系吗？若完全消失，说明方案过度依赖素材表面的风格，应重新建立逻辑。这是设计者自检，未实际向读者测试时不得报告为用户测试。
