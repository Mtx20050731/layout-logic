# Layout Logic · 版式逻辑

把内容目标转为可阅读、有秩序、有记忆点的版式。以信息层级和可调整的网格为底架，用构图、点线面、留白、图文层次和必要的空间感服务表达。默认中文回应；用户指定语言、精确文案、风格、尺寸和媒介时遵从其要求。

## 先确定工作范围

创建作品时完成可查看的成品，评审时给具体修改。用户仅要规范或分析时，不自行扩展为设计制作。

先从已有材料识别：受众与任务、完整文案、核心主体、必留信息、输出尺寸/观看条件、品牌或参考的约束。缺少会改变结果的信息时才询问；可推断的选择写明假设并继续。不要重新询问用户已确定的内容，也不要固定要求“三个方向”或每步审批。

本 Skill 提供版式决策。制作 PPT、PDF、图片或页面时，沿用当前环境可用的媒介工具/流程；有用户明确指定的风格技能时，将本 Skill 仅作为兼容的版式补充，不导入其他风格的色数、材质或构图规则。尺寸、署名、商标、精确文案和素材保真要求优先。

## 必须完成的判断

1. **建立阅读路径**：写出第一眼识别什么、继续阅读什么、细读/行动需要什么。艺术或展览海报可以保留主题的含义悬念，日期、地点、品牌等必要事实仍要能检索。
2. **选结构**：按内容量与素材选主轴、对角、上下、左右、边缘或模块式关系；记录版心、主要对齐线、间距和字级。网格是布局的关系系统，透视网格只是营造纵深的方法。
3. **分配重量与呼吸**：同时考虑尺寸、字重、明暗、面孔、色彩和留白。先用共同边缘、基线、视线等隐性关系组织信息，再决定是否添加可见线、色块和装饰。
4. **选择表达机制**：由主题产生一个可说明的视觉动作，例如几何归纳、重复中的例外、文字沿主体走势、正负形、图文穿插。简单项目只做必要调整；多种动作并用时确认它们支持同一主题。不要强制“一幅画只能一个效果”。
5. **在成品条件验证**：检查真实字号、对比、裁切、遮挡、断行、主体识别和信息完整。多页/多尺寸项目分别检查一致性与重排。没有实际渲染或读者测试时如实说明，不把“预计清楚”写成“已通过验证”。

## 输出与修订

生成可查看的作品或可执行的排版方案；根据任务给出必要的网格/字级/色彩参数，标明单位、用途及假设。避免只说“增加高级感”。评审用“位置—问题—影响—调整”的格式指出主要问题，先修内容和可读性，再修结构，最后精调表现。

交付前简短核对主体识别、层级构图、色彩材质、字体可读、负空间、参考图职责与输出格式；说明成立之处、实际冲突和具体调整。保留内容与识别底线，按用户意图处理风格；艺术性实验可以改变阅读节奏，但不能悄悄删掉必需事实。

精读书籍、渲染、字体嵌入、印前、真实观看或用户测试，只有做过才报告完成。引用区分档案事实、画面观察与本 Skill 的整合建议。后者不是设计师原话。
